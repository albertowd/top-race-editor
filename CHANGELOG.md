## 0.1.0

- First version of the editor.
- Draw roads as curves over the satellite picture.
- Add rumbles, lines and paint along the roads.
- Place each layout's grid, pits, timing gates and racing lines.
- Place cones, boards, light poles, tyre walls, trees and buildings.
- Shape the terrain.
- Add bumps to the roads by hand.
- Paint wear and rubber marks where the cars drive.
- Build the track for Assetto Corsa, BeamNG.drive and rFactor 2.
- Install the built track in each game.
- Build a track from the command line.
- Layout pictures rendered from the built track.
- rFactor 2: working start lights on the gantries.
- rFactor 2: gantry boards with the track's and the layout's names.
- rFactor 2: a spot for each layout's safety car to wait.
